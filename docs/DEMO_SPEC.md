# Speller — 玩法 Demo 开发文档 v1.0

> 本文档是 Codex 的执行依据。设计部分（第 1–7 章）描述"做什么"，技术部分（第 8–10 章）描述"怎么做"，第 11–12 章是里程碑与验收。
> 所有数值都是**初始值**，允许在实现中调参，但要保持文中写明的设计意图。

---

## 0. 一句话目标

做一个 **单关卡、约 8–12 分钟** 的网页可玩 Demo：玩家（白色小方块）在一段歪歪扭扭的手写文字世界中跑酷，通过**重排单词**改变世界——先用 `PALM → LAMP` 照亮黑暗，再主动收集字母拼出 `LISTEN` 看清声控机关、拼出 `SILENT` 静音冲过终点。

**玩家应当感受到两件事同时成立：**
1. 这是一个手感扎实、有距离设计的跑酷游戏；
2. 地图上的每一行字都在跟玩家开玩笑，而且字本身就是地形。

### 绝对不要做的事
1. 不要把文字当成背景贴图——白色文字一定是可站立的地形。
2. 不要把文字地形替换成矩形平台（动态物件见 §8.4 的例外）。
3. 不要在第三段之前要求按 S 收集字母；`PALM` 必须整词自动载入。
4. 不要自动给出完整的 `LISTEN`，六个字母必须分散收集。
5. 不要让施法只触发过关动画——每个法术都必须改变可玩的环境状态。
6. 不要在拼词或施法时暂停游戏（"子弹时间"减速除外，见 §5.6）。
7. 不要引入外部美术素材或字体文件；所有文字由代码中的单笔画字形数据绘制。
8. **不要自行编写、修改或删减任何作者文案。** 所有吐槽、批注、彩蛋台词、幽默地形文字都以 [AUTHOR_LINES.md](AUTHOR_LINES.md) 为唯一来源（见 §0.1）。

### 0.1 作者文案审批规则（适用于全文）
- 本文档中出现的所有作者文案（灰色批注、彩蛋台词、兜底吐槽、死亡吐槽、幽默地形词句、角色台词）都只是**占位示例**，必须经过作者审批。
- 所有文案统一登记在 `docs/AUTHOR_LINES.md`，每条有唯一 ID（如 `N01`）和状态（`待审` / `已批准` / `已修改` / `已删除`）。
- 代码中所有面向玩家的文案集中放在 `src/content/lines.ts`，以 ID 引用，**禁止在其他代码中硬编码文案字符串**。
- 实现时一律使用 AUTHOR_LINES.md 中的当前文本。状态为 `已删除` 的条目不显示。
- 如果实现中发现需要一条清单里没有的新文案，**不要自己写**：在 `lines.ts` 中使用占位文本 `[TODO: Nxx]`，并在 AUTHOR_LINES.md 末尾追加一条状态为 `待写` 的新条目，说明位置和用途。
- 调试菜单提供一个开关："高亮未批准文案"——开启后，状态不是 `已批准` 的文案显示为洋红色，方便作者巡查。

## 1. 视觉规范

### 1.1 颜色语义（严格执行，这是玩家理解规则的唯一依据）

| 颜色 | 色值 | 含义 | 可碰撞 |
|---|---|---|---|
| 纯黑 | `#000000` | 背景 / 虚空 | — |
| 白色 | `#F2F2F2` | 普通地形文字 | ✅ |
| 灰色 | `#7A7A7A` | 作者的小字批注（吐槽、提示），**纯装饰** | ❌ |
| 浅黄 | `#FFE27A` | **可收集字母**（嵌在白色单词中） | ✅ |
| 绿色 | `#7CFF8A` | **已收集字母**（原地保留，不消失，仍是地形） | ✅ |
| 浅蓝 | `#8FD8FF` | **可重排单词**（走上去整词载入拼词栏） | ✅ |
| 红色 | `#FF5A5A` | 危险（尖刺）、声控机关的状态与范围 | 尖刺=致死 |
| 暖白光 | `#FFF4D0` | LAMP 光圈 | — |
| 玩家 | `#FFFFFF` 实心方块 + 轻微外发光 | 玩家 | — |

规则：
- 一个单词里可以只有某一个字母是浅黄色，其他字母保持白色（例如 `HE`**`L`**`LO`）。
- 浅黄字母被收集后**只变色，不消失，不改变地形**。
- 浅蓝单词施法成功后变回白色，成为普通地形，不再可载入。

### 1.2 手绘感
- 所有文字用**单笔画矢量字形**（类似 Hershey 字体）绘制，线宽 3–5px，圆头线帽。
- 每个文字对象有固定随机种子（seed），决定：
  - 每个字母旋转 ±5°、缩放 0.92–1.08、基线上下偏移 ±4% 字高；
  - 每个顶点抖动 ±3% 字高。
- **同一个 seed 必须同时用于渲染与碰撞生成**，保证"看到的就是踩到的"。
- 文字对象可以沿直线（带旋转角）或曲线基线（折线/二次贝塞尔）排列，字母随切线旋转。
- P1：渲染层每 120ms 用微小的额外抖动（±1px）重绘一次，模拟"线条沸腾"；**这一抖动不影响碰撞**。

### 1.3 字号档位
单位：`U = 32px`。

| 档位 | 字高 | 用途 | 碰撞 |
|---|---|---|---|
| XL | 4U (128px) | 地标词：`PLATFORM`、`GRANDPA`、`NEXT` | ✅ |
| L | 2.5U (80px) | 常规地形词 | ✅ |
| M | 1.6U (51px) | 小平台、台阶 | ✅ |
| S | 1.25U (40px) | 提示句桥梁（最小可碰撞字号） | ✅ |
| Note | 18–22px | 灰色批注 | ❌ |

所有地形文字统一使用**大写**。灰色批注可以用大小写混排。

### 1.4 屏幕与镜头
- 逻辑分辨率 1280×720，等比缩放适配窗口。
- 镜头平滑跟随，带水平前瞻（朝移动方向偏移 3U），垂直方向有 2U 的死区。
- 屏幕上方中央常驻拼词栏（§5）。

## 2. 操作

| 按键 | 功能 |
|---|---|
| A / D（及 ← / →） | 左右移动 |
| W（及 ↑） | 跳跃（按住时间越长跳得越高） |
| S（及 ↓） | 收集附近的浅黄字母 |
| **Space** | 提交拼词栏中的单词（施法） |
| 鼠标左键拖动 | 在拼词栏内移动字母（插入式） |
| 鼠标左键点击两个字母 | 交换这两个字母 |
| Backspace | 删除拼词栏中已收集的字母（优先删选中项，否则删末尾；仅限绿色字母） |
| Ctrl/Cmd + Z，或拼词栏右侧 ↺ 按钮 | 撤销上一步排列或误删 |
| R | 回到最近的检查点 |
| Esc | 暂停菜单 |
| F1 | 调试菜单（§10） |

鼠标操作期间**角色仍然受键盘控制**，游戏不暂停。

## 3. 角色移动参数（跑酷手感的基础）

| 参数 | 值 | 备注 |
|---|---|---|
| 玩家尺寸 | 24×24 px (0.75U) | |
| 最大跑速 | 260 px/s | ≈ 8.1 U/s |
| 地面加速度 / 减速度 | 2200 / 2600 px/s² | |
| 空中控制系数 | 0.8 | 空中加速度 = 地面 × 0.8 |
| 重力 | 1800 px/s² | |
| 起跳速度 | 640 px/s | |
| 松开跳跃键截断 | 若仍在上升，速度 × 0.45 | 实现可变跳高 |
| 最大下落速度 | 900 px/s | |
| Coyote time | 0.10 s | 离开边缘后仍可起跳 |
| 跳跃缓冲 | 0.12 s | 落地前按跳也有效 |
| 可行走最大坡度 | 50° | 更陡视为墙 |
| 落地下吸距离 | 8 px | 下坡时贴地，不腾空 |

由此推出（满速、同高度）：
- **最大跳高 ≈ 114px ≈ 3.5U**
- **最远平跳 ≈ 185px ≈ 5.8U**

### 3.1 间距设计标尺（关卡搭建必须遵守）

| 档位 | 水平间隙 | 向上高差 | 使用比例 |
|---|---|---|---|
| 舒适 | ≤ 3.5U | ≤ 2.0U | ~60% |
| 标准 | ≤ 4.5U | ≤ 2.8U | ~30% |
| 极限 | ≤ 5.2U | ≤ 3.2U | ≤ 10%，只放在冲刺段 |

- 任何需要跳过的间隙都不得超过 5.2U（除非借助 BOUNCY）。
- 致死坑之前至少要有一次同档位、但不致死的练习。
- 文字碰撞面凹凸不平，起跳点和落点要预留 ≥ 1U 的平整区域（尽量选用 `E F H L T` 等顶部平直的字母作为落点）。

## 4. 世界对象一览

### 4.1 文字对象（静态地形）
每个文字对象：`text, x, y, size, rotation | baseline 曲线, seed, color role, oneWay?`
- `oneWay: true`：只能从上方站上去，从下方和侧面可以穿过（用于省略号、提示句桥梁等）。
- 默认是实心。

### 4.2 行为词（"说什么就是什么"）
单词本身的意思就是它的物理规则，**不需要任何教程文字**。

| 单词 | 颜色 | 行为 | 参数 |
|---|---|---|---|
| `BOUNCY` | 白 | 踩上去字母压扁，把玩家弹起 | 弹射速度 980 px/s（≈ 8U 高） |
| `CRUMBLY` | 白 | 被踩到的字母 0.35s 后碎裂下落，3s 后重新长出 | 逐字母判定 |
| `NERVOUS` | 白 | **声控**：听到声音后抖动 0.6s，然后整词下坠；4s 后复位 | 见 §7 |
| `TICK TOCK` | 白 | **节拍器**：每 2.4s 发出一次声波脉冲（不受玩家控制） | 见 §7 |
| `DOOR` | 白（竖排） | **声控门**：被 GRANDPA 控制，听到声音就关闭 | 见 §7 |

### 4.3 标点符号地形
- `...`：三个 1U 宽的小落脚点（oneWay），用来连跳。
- `!`：细长柱子，顶端可站立。
- `?`：弯钩作为弧形坡道。
- `.`：句号可作为句子末尾最后一个落脚点。

### 4.4 危险物
- **尖刺**：红色锯齿线，藏在文字之间的缝隙里。收起时只显示一排红色小点（读作"这里有东西"）；伸出时致死。
- **虚空**：掉出地图底部（kill plane）即死亡。

### 4.5 检查点
手写的 `SAVE` 字样（M 号，白色，可站立）。玩家经过后，字母依次变为浅绿并闪一下。

## 5. 拼词栏（核心 UI）

### 5.1 外观
- 固定在屏幕上方中央，始终显示。
- 最多 8 个槽位，每个字母是一个手绘方框里的手绘字母。空栏显示 3 条淡淡的下划线 `_ _ _`。
- 字母颜色跟随来源：蓝词载入的显示浅蓝，收集来的显示绿色。
- 右侧有 ↺ 撤销按钮和一个小提示 `SPACE`。

### 5.2 载入规则

**A. 蓝词整词载入**
- 玩家碰撞盒接触蓝词任意字母的碰撞区域时触发。
- 拼词栏内容替换为该词的字母（按原顺序），并记录来源 `word:PALM`。
- 如果栏中已经是同一个蓝词，**不做任何改变**（保留玩家已经排好的顺序）。
- 载入动画：字母从地图飞向拼词栏（0.3s）。

**B. 浅黄字母收集**
- 玩家中心与浅黄字母的距离 ≤ 1.5U 时，字母上方出现手绘的 `S` 提示并轻微跳动。
- 按 S：地图上的字母变成绿色（**原地保留、碰撞不变**），一个副本飞入拼词栏，**追加到末尾**。
- 同时有多个可收集字母时，收集最近的那个。

**C. 冲突保护**
- 关卡设计保证这两种来源不会同时出现（PALM 在第 1 段就会被用掉）。
- 实现上仍需保护：蓝词载入时，已收集的字母先暂存；蓝词施法成功后恢复。

### 5.3 重排与删除操作
- **拖动**：按住字母拖到目标位置松手，按插入方式重排（其他字母依次挪开），带吸附动画。
- **点击交换**：先点一个字母（高亮），再点另一个，两者交换。点同一个字母则取消选择。
- **删除（Backspace）**：仅对收集来的**绿色字母**生效（浅蓝整词不可删除单个字母）。若有鼠标点选高亮的字母，则删除该字母；否则删除末尾字母。被删除的字母在地图原位恢复为**浅黄色**（可重新按 S 收集），避免永久卡关。
- **撤销（Ctrl/Cmd+Z 或 ↺）**：记录每次排列与删除的快照，回退一步；撤回删除时，字母回到拼词栏原位，地图上对应字母同步变回绿色。

### 5.4 提交（Space）
1. 取拼词栏中**全部字母**按当前顺序组成字符串。
2. 依次查询：法术表（§6）→ 彩蛋表（§6.5）→ 兜底反馈。
3. 匹配法术：字母发光、向上飘散一圈线条、执行效果。
4. 匹配彩蛋：执行彩蛋效果，并在附近出现灰色批注。
5. 都不匹配：字母左右抖动 0.3s，从兜底吐槽池随机显示一句批注。
6. 施法成功后：
   - 来源是蓝词：清空拼词栏，原蓝词变白；
   - 来源是收集字母：**保留在栏中**，保持施法时的顺序。

### 5.5 法术前置条件
- 法术有生效区域（例如 LAMP 只能在黑暗区使用）。区域外施放时字母抖动，显示批注 *"Not here. Not now."*
- 冷却中的法术：栏中字母显示为暗色并带圆形进度条，此时按 Space 无效。

### 5.6 子弹时间（P0，默认开启，可在暂停菜单关闭）
按住鼠标拖动字母时，整个游戏世界（物理、机关、计时器）放慢到 **0.4 倍速**；松开后在 0.15s 内恢复正常。画面边缘出现轻微暗角。
设计意图：允许玩家在危险中一边跑一边拼词，而不是必须停下来。

## 6. 法术与彩蛋

### 6.1 LAMP（来自蓝词 PALM）
- **生效区域**：黑暗区（第 1–2 段）。
- **效果**：
  - 一盏简笔画台灯（灯罩 + 灯泡 + 几条光线）出现在玩家头顶 1.2U 处，跟随玩家移动，带轻微摆动；
  - 可见半径在 1.2s 内从 2U 扩大到 **9U**，边缘有柔和渐变；
  - 9U 必须大于任何标准跳跃距离，保证下一个落脚点总在光圈内。
- 持续到黑暗区结束（见第 2 段结尾）。

### 6.2 LISTEN（来自收集字母）
- **生效区域**：全图（实际只在声控区有意义）。
- **效果（永久，直到 Demo 结束）**，开启"声音可视化"：
  - 玩家每次发出声音，都显示一个白色半透明扩散圆环，大小等于声音半径；
  - 每个声控机关显示红色虚线的"听觉范围"；
  - 节拍器的脉冲显示为红色扩散圆环，节拍器旁有一个倒计时弧线，显示下一次脉冲的时间；
  - 受节拍器影响的尖刺上方，显示与节拍同步的小闪点。
- 施法瞬间：全屏一圈声波从玩家向外扩散，所有机关依次亮出范围（0.8s）。

### 6.3 SILENT（来自收集字母）
- **生效区域**：全图。
- **效果**：静音 **12s**。
  - 玩家的移动、跳跃、落地都不产生声音事件；
  - 画面去饱和（只保留红色和绿色），玩家变成只有轮廓的方块，脚步粒子消失；
  - 拼词栏下方显示倒计时条，最后 3s 闪烁并伴有滴答声。
- **冷却**：效果结束后 2s 冷却，之后可以直接再按 Space 重新施放（栏中仍是 SILENT，无需重排）。
- 死亡后静音立即结束，冷却清零。
- **SILENT 只让玩家安静**，环境声源（节拍器）照常工作。

### 6.4 SWORD（来自蓝词 WORDS，新增法术 / 关卡机制）
- **设计原则**：**不额外增加攻击键**，依然沿用 `Space` 提交施法。
- **生效区域**：`WORDS` 蓝词及对应绳索机关所在区域（玩家通常直接站在 `WORDS` 上完成重排并施法）。区域外施法遵循 §5.5 不消耗。
- **效果**：
  - 提交 `SWORD` 后，剑在**固定位置**自动生成并挥出（可将 `S-W-O-R-D` 字母形态化作手绘长剑与弧形剑光），自动斩断目标绳索——**保证不会挥空**；
  - 绳索本身也是文字对象（如竖排 `ROPE` / `STRING` 等）；
  - 绳索斩断后，所悬挂的地形物体（例如竖悬的 `BRIDGE` 倒下成为可通行横桥，或重物坠落砸开下方通路）发生状态变化，真正改变可玩地形；
  - 斩断完成后，按蓝词规则清空拼词栏，原 `WORDS` 变白。

### 6.5 彩蛋表（拼对单词但不是法术）

| 输入 | 效果 | 灰色批注 |
|---|---|---|
| `PALM`（未改动就提交） | 一只手绘手掌在玩家头顶挥了挥手 | *"That's just your hand."* |
| `WORDS`（未改动就提交） | 若干手绘字母/气泡从玩家头顶飘散 | `[TODO: E08]` |
| `TINSEL` | 附近的文字上挂满一串闪烁彩条，8s 后掉落 | *"Wrong season."* |
| `ENLIST` | 一个火柴人小兵从地里冒出来敬礼，然后齐步走出屏幕 | *"He'll be back. (He won't.)"* |
| `INLETS` | 玩家脚下出现一小滩水，水花四溅 | *"Technically correct. Useless, but correct."* |
| `LIST`（只有这四个字母时） | 弹出一张手写清单，列出已收集/未收集的字母，未收集的位置附带一句模糊提示（例如 *"N: somewhere nervous"*） | *"Organized. I like that."* |
| `TEN` / `NET` | 头顶出现"10/10"/一张小网兜住玩家后散开 | *"Generous."* / *"Caught you."* |
| `SILENT` 已在冷却中再次提交 | — | *"Shh. Still recharging."* |

> 彩蛋必须**纯表现**，不能改变地形或碰撞，避免玩家借此绕过谜题或卡关。`LIST` 例外：它只提供信息。

**兜底吐槽池**（随机、不连续重复）：
- *"That's not a word. I checked."*
- *"Bless you."*
- *"Even I can't read that."*
- *"Close. Not really."*
- *"Is that a password?"*

## 7. 声音系统（第 4–5 段）

### 7.1 声音事件
| 动作 | 声音半径 |
|---|---|
| 地面奔跑（每 0.25s 一步） | 1.5U |
| 起跳 | 3U |
| 落地 | 3U + (落地速度 / 900) × 4U，即 3–7U |
| 静止 / 空中滑行 | 无声 |

设计意图：**跑步声小、大落差落地声大**。玩家可以通过小跳、选择落点来控制噪音，LISTEN 让这条规律变得可见。

### 7.2 声控机关
每个机关有一个矩形 `hearZone`。当声音圆与 hearZone 相交时，机关被触发。

| 机关 | 触发后 | 复位 |
|---|---|---|
| **声刺**（尖刺带） | 0.12s 内伸出，保持 1.0s 后收回 | 收回后才能再次触发 |
| **NERVOUS** | 抖动 0.6s 后下坠 | 4s 后在原位淡入 |
| **GRANDPA + DOOR** | GRANDPA 醒来，头顶冒出 *"WHO'S THERE?!"*，DOOR 立即关闭 | 最后一次声音之后 3s，GRANDPA 重新入睡（`Z z z`），DOOR 打开 |
| **TICK TOCK**（节拍器） | 本身是声源：每 2.4s 发出半径 6U 的脉冲，触发范围内的声刺 | — |

### 7.3 LISTEN 前后的可读性
- **LISTEN 之前**：玩家能看到机关的**反应**（尖刺伸出、平台抖动、GRANDPA 醒来、红色的"!"线条脉冲），并能听到音效。但看不到**原因**（声音圆）和**范围**（hearZone）。
- **LISTEN 之后**：原因、范围、节拍时机全部可见（§6.2）。
- 不依赖听觉：所有触发都有视觉反馈。

## 8. 关卡设计（单关，六段）

整体流程：

```
[0 开场跑道] → [1 黑暗] → [2 点灯跑酷] → [3 收集教学] → [4a 声控收集] → [4b LISTEN 尖刺廊] → [5 SILENT 冲刺] → NEXT
   ~1.5min      ~1min       ~1.5min        ~0.5min        ~1.5min          ~1.5min             ~1.5min
```

坐标约定：x 向右、y 向上，单位 U，地面基准 y=0。下面的 x 区间是大致范围，Codex 可以在满足 §3.1 的前提下自由微调。**每一段都要在关卡数据中用注释标出对应的节拍编号（如 `// 0.4 MIND THE GAP`）。**

### 第 0 段：开场跑道（x 0–150）
目的：教会移动和跳跃，展示"字就是地"，建立幽默基调。全段只有 0.4 之后出现致死坑。

| 节拍 | 内容 | 跑酷要求 | 批注 |
|---|---|---|---|
| 0.1 | 出生在 L 号单词 `HERE` 上 | — | *"You are here. Obviously."* |
| 0.2 | XL 号 `PLATFORM`，约 20U 长，字母顶部形成起伏 | 跑过凹凸地形 | *"Yes, you can stand on words. Don't make it weird."* |
| 0.3 | M 号 `STEP STEP STEP`，每个比上一个高 1.5U，间隙 2U | 舒适跳 | — |
| 0.4 | `MIND THE` ⟶ 间隙 3.5U ⟶ `GAP`，下方是虚空（第一处致死坑）。坑底写一句灰色批注 | 舒适跳 | 坑底：*"told you."* |
| 0.5 | `...` 三个点，间隙 3U / 4U / 4.5U，悬在虚空上 | 舒适→标准 | *"Pause for dramatic effect."* |
| 0.6 | `BOUNCY` 前方是一面 6U 高的墙（普通跳上不去） | 发现弹跳 | 墙上：*"Too high? Read the floor."* |
| 0.7 | 墙顶是 12U 长的 `CRUMBLY` 桥横跨深坑 | 不能停顿 | *"Keep moving. Seriously."* |
| 0.8 | 落到 `DON'T FALL.` 上，句号 `.` 是最后一个落脚点，从句号起跳 4U 进入第 1 段 | 标准跳 | — |

### 第 1 段：黑暗（x 150–205）
目的：引入黑暗和浅蓝单词，教拼词栏操作。**本段没有致死危险。**

- 入口处放检查点 `SAVE`。
- 进入后黑暗遮罩生效：玩家周围只能看见半径 2U，边缘柔和。
- 地面是一段平缓、不连续但间隙很小（≤ 1.5U）的白色单词，在黑暗中只能被光圈照到（例如 `SOME FLOOR`、`MORE FLOOR`、`STILL FLOOR`——玩家只能看见脚下这一个词，本身就是笑点）。
- 一句**自发微光**的提示句作为斜向上的桥梁（S 号，oneWay，不需要光照也可见）：

  `TOO DARK TO SEE ANYTHING? THE LIGHT LIES WITHIN THE `**`PALM`**` OF YOUR HAND.`

  其中 `PALM` 为浅蓝，L 号放大，位于桥的末端，是桥上必经的一段。`LIGHT` 保持白色，不做强调。
- PALM 旁边的灰色批注（同样自发微光）：
  *"Light blue words can be rearranged. Drag the letters up there. SPACE to cast."*
  并画一个指向屏幕顶部拼词栏的手绘箭头。
- PALM 之后就是第 2 段的起点：前方虚空、平台不可见。
- 检查点：在 PALM 前再放一个 `SAVE`。施法前如果摸黑跳进第 2 段而死亡，会回到这里。

### 第 2 段：点灯跑酷（x 205–300）
目的：让 LAMP 的效果变成**可玩的视野**，而不是一个动画。

- 光圈半径 9U，地图其余部分仍是黑暗。

| 节拍 | 内容 | 跑酷要求 |
|---|---|---|
| 2.1 | `STEP` 阶梯在灯光中显现，向上越过虚空，间隙 3U，高差 1.5–2U | 舒适跳 |
| 2.2 | 一排 M 号 `I` 竖柱（顶部 1U 宽），间隔 4U，高度起伏 ±1.5U；批注 *"I, I, I. It's all about me."* | 标准跳，节奏感 |
| 2.3 | 检查点 `SAVE` | — |
| 2.4 | 长句桥，S 号，沿向下凹的弧线跨越深坑：`THIS SENTENCE IS UNNECESSARILY LONG BECAUSE THE GAP IS UNNECESSARILY WIDE.` | 持续奔跑 + 弧线底部一次 3U 的小间隙 |
| 2.5 | `WHERE AM I GOING` 后面跟一个 XL 号 `?`，问号的弯钩是一段向上的弧形坡道，坡顶接一次 4.5U 标准跳 | 坡道冲刺 + 跳 |
| 2.6 | 黑暗结束：落到亮处（无遮罩）的 `FINALLY` 上。台灯闪烁两下熄灭，飘向屏幕外 | 批注：*"Thanks, LAMP. You're free now."* |
| 2.7 | 经过 `SAVE` 后踩上浅蓝色 `WORDS`，按 §6.4 拼出 `SWORD` 斩断文字绳索 `ROPE` | 走过放下的 `BRIDGE`，进入收集教学 |

### 第 3 段：收集教学（x 300–340）
目的：教会 S 键和浅黄色。**本段完全安全，没有坑。**

- 检查点 `SAVE`。
- L 号 `HELLO`，第一个 `L` 为浅黄，就在必经路线上，伸手可及。
  批注：*"Yellow letters can be taken. Press S. (They stay. We're not thieves.)"*
- 一根 XL 号 `!` 的柱子，顶端是 M 号 `HI`，其中 `I` 为浅黄。需要先跳上旁边 2U 高的 `LEDGE`，再跳上柱顶。
- 收集第一个字母后，拼词栏旁临时出现批注：*"Collected letters stay up here. Shuffle them anytime."*

### 第 4a 段：声控收集（x 340–420）
目的：在**不致死**的环境中让玩家体验"声音会触发机关"，并收集剩下 4 个字母。

- 入口检查点 `SAVE`。
- L 号 `SHHH`，第一个 `S` 为浅黄。批注：*"Quiet area. Mostly."*
- **4a.1 NERVOUS 平台组**：三个 M 号 `NERVOUS` 横跨一段**浅坑**（坑底是一条名为 `DOWNSTAIRS` 的白色地面，会通过 `STEP` 绕回坑前，只损失时间、不会死）。第二个 NERVOUS 的 `N` 为浅黄。落地声音会让它开始抖动，玩家需要在 0.6s 内收集并跳走（或在旁边一个 NERVOUS 上收集，收集半径 1.5U）。
  批注：*"They get nervous when you land loudly."*
- **4a.2 LEAP**：一次 4.5U 标准跳（下方仍是浅坑），落点是 L 号 `LEAP`，其中 `E` 为浅黄。
- **4a.3 节拍器演示**：XL 号 `TICK TOCK`，上方有一根摆锤线条左右摆动。脉冲每 2.4s 触发**附近一排不在路线上的**声刺（只作演示）。`TOCK` 的 `T` 为浅黄，位于脉冲范围内但没有尖刺的安全位置。
  批注：*"It's not you. It's the clock. (Sometimes it's you.)"*
- 本段结束时玩家应当已经有 L I S N E T 六个字母（顺序取决于收集顺序，通常是 `L I S N E T`）。
- **门槛**：如果离开 4a 时字母不足 6 个，出口处的 `SAVE` 旁显示批注 *"Missing something? Six letters. Count them."*，但不强制阻拦。

### 第 4b 段：LISTEN 尖刺廊（x 420–490）
目的：致死的声控区。LISTEN 让规律可见，但不施放 LISTEN 也可以通过观察通过。

- 入口检查点 `SAVE`。
- 入口处的提示句桥（S 号）：`SOMETIMES YOU NEED TO LISTEN BEFORE YOU MOVE.`
- **4b.1 落点选择**：一连串高低错落的单词平台，地面缝隙中藏着声刺。声刺的 hearZone 设计成：在平台上**奔跑**的脚步声（1.5U）碰不到，但从高处**大落差落地**（> 4U）会触发。可通过的路线是"一连串小落差跳"。LISTEN 后可以清楚看到声音圆与红色区域的关系。
- **4b.2 节拍器尖刺带**：第二个 `TICK TOCK` 的脉冲覆盖一段 6U 长的低矮通道，通道顶部是声刺。脉冲周期 2.4s：尖刺伸出 1.0s，收回 1.4s。玩家需要在收回窗口内穿过（满速 6U ≈ 0.74s）。LISTEN 后有倒计时弧线辅助判断时机。
- **4b.3 LISTEN 奖励路线**：施放 LISTEN 后，原本难以辨认的一条高处路线（由 `TIPTOE` 等单词组成，悬挂在声刺 hearZone 之外）变得一目了然——玩家能看出走这条路完全不会触发尖刺。不施放 LISTEN 的玩家仍然能看到这些单词，只是不知道它们是安全的。
- 出口检查点 `SAVE`。

### 第 5 段：SILENT 冲刺（x 490–580）
目的：整个 Demo 最难的一段纯跑酷，必须在静音中完成。

- 检查点 `SAVE` 是一块安静的起跑平台（不在 GRANDPA 的听觉范围内）。
- 起跑平台前的提示句（S 号，始终可见，不依赖是否施放过 LISTEN）：
  `KNOWING WHEN TO LISTEN IS USEFUL. KNOWING WHEN TO BE SILENT IS BETTER.`
- XL 号 `GRANDPA` 躺在高处，头顶飘着 `Z z z`。他的 hearZone 覆盖 x 495–570 的整个区域。
- 终点前是竖排的 L 号 `DOOR`（x ≈ 570）。只要 hearZone 内有任何声音，门就关闭。由于移动必然发出声音，**不施放 SILENT 不可能通过**。
- 起跑平台到 DOOR 之间的跑酷内容（总长约 75U，理想路线约 8–9s，SILENT 给 12s）：
  1. 两个 `NERVOUS` 横跨致死坑（静音下它们不会抖）；
  2. 一段 `CRUMBLY` 桥（与声音无关，仍会碎）；
  3. `...` 三连点，包含一次 5.2U 的极限跳；
  4. 一段由 `TICK TOCK` 脉冲控制的声刺（环境声源，SILENT 无法阻止），需要卡时机——LISTEN 的倒计时弧线在这里帮助很大；
  5. 一次 BOUNCY 弹到门前平台。
- 半路如果静音结束：GRANDPA 醒来、门关闭，但**不会直接致死**。玩家可以原地站 3s 等他入睡，并在冷却结束后重新施放 SILENT 继续。
- 穿过 DOOR 后是 XL 号 `NEXT`。玩家站上 `NEXT` 即通关。

### 通关画面
- 黑屏上手写浮现：`DEMO COMPLETE`
- 统计：用时、死亡次数、找到的法术 x/4、找到的彩蛋 x/8。
- 批注：*"More words coming. Probably."*
- 按 R 从头开始。

## 9. 死亡、重试与作者互动

- 死亡：玩家碎成 4 个小方块，0.4s 后在最近的检查点复活。
- 死亡时重置：机关状态、CRUMBLY / NERVOUS、SILENT 效果。
- 死亡时保留：已收集的字母（绿色状态）、已获得的 LAMP（仍在黑暗区时）、LISTEN、拼词栏内容。
- **作者吐槽**：每个检查点区间单独统计死亡次数。
  - 第 3 次死亡：在死亡位置附近出现一句灰色批注（每个区间预设 1–2 句，例如 *"You again?"*、*"The floor is right there."*）。
  - P1，第 6 次死亡：在该区间预设的"辅助点"生成一个白色 `,` 小台阶，降低一处最难的跳跃。批注：*"Fine. Here's a comma."*
- **不可永久卡关**：任何时候按 R 都能回到检查点；任何收集字母即使被 `Backspace` 删除也会在地图原位恢复为浅黄色（且可用 `Ctrl/Cmd+Z` 撤回），不会永久丢失；任何机关都会复位。

## 10. 技术方案

### 10.1 技术栈
- **TypeScript + Phaser 3 + Vite**，浏览器运行。
- 单元测试：**Vitest**（覆盖纯逻辑模块）。
- 不使用 Phaser 内置的 Arcade/Matter 物理处理玩家与文字的碰撞——使用下面的**自定义掩码碰撞**。
- 音效（P1）：用 WebAudio 代码合成（短促的方波/噪声包络），不引入音频文件。

### 10.2 目录结构

### 10.3 字形与手写
- `glyphs.ts`：每个字符是一个笔画数组，每个笔画是归一化坐标（0–1 方框，宽度可变）中的折线点列表，并记录字符的步进宽度。
- `handwriting.ts`：`(text, size, seed, baseline) → 每个字母的世界坐标笔画折线`。使用确定性 PRNG（例如 mulberry32）。
- **同一输出同时用于**：Phaser Graphics 绘制、碰撞掩码光栅化、可收集字母 / 蓝词的命中区域。

### 10.4 碰撞：掩码网格
- 全关卡一张静态碰撞掩码：格子 **4px**。
- 光栅化：每个白色/黄色/绿色/蓝色文字对象的每段笔画，按**碰撞粗细 = max(10px, 视觉线宽 + 6px)** 的胶囊体填充格子。这样细笔画也有容错。
- `oneWay` 对象写入单独的一张掩码层：只有当玩家正在下落，且上一帧脚底高于该格顶部时才产生碰撞。
- **玩家移动**（每帧，按像素子步进）：
  - 水平：逐像素尝试移动。被挡时，检测前方 8px 处的地面高度。若坡度 ≤ 50°（即上升 ≤ 9.5px），则抬升后继续前进；否则视为墙。
  - 垂直：逐像素移动，碰撞后速度清零。
  - 着地时向下探测 8px，贴地（避免下坡腾空）。
- **动态物件**（BOUNCY、CRUMBLY 的单个字母、NERVOUS、DOOR）不写入静态掩码，而是各自持有碰撞体。允许使用**简化矩形**（取文字包围盒的上部 / 单个字母包围盒），但这些单词必须写在笔直的基线上，使视觉顶面与矩形顶面一致。
- 调试视图（F1）中必须能把碰撞掩码叠加显示为半透明网格，用来核对"看到的 = 踩到的"。

### 10.5 黑暗与光圈
- 用一张全屏 RenderTexture 填充黑色，每帧在玩家位置擦除（erase）一个径向渐变圆。
- 自发光对象（提示句、PALM、批注）绘制在遮罩**之上**的图层。
- 黑暗区由关卡数据中的 x 区间定义，进入/离开时遮罩淡入/淡出。
